# Charulata Chauhan - Enterprise AI Portfolio

Interactive portfolio presenting enterprise AI automation, applied AI, SAP workflows, MCP integrations, forecasting, NLP and analytics through evidence-led case studies.

## Recommended public address

Create a public repository named exactly `charu-1727.github.io`. GitHub Pages will publish it at:

`https://charu-1727.github.io`

The included GitHub Actions workflow builds and publishes the website automatically after every push to `main`.

## Local development

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run dev`.

## Deploy

1. Upload these files to the `main` branch of `charu-1727.github.io`.
2. Open repository Settings > Pages.
3. Set Source to `GitHub Actions`.
4. Open the Actions tab and confirm the deployment workflow succeeds.

The site also supports a normal project repository name. In that case, it automatically uses the repository name as the GitHub Pages base path.

## Public-data rule

Do not add company credentials, internal URLs, confidential screenshots, private datasets or proprietary source code. Company names may be shown, but implementation details must remain sanitized.
